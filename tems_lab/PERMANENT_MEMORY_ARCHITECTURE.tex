\section{Requirements}
\begin{enumerate}[itemsep=0pt]
\item \textbf{Core tool, NL-driven} — ``hey Tem, remember my birthday'' just works; no slash commands.
\item \textbf{Self-sustaining, no repetition} — the agent curates; the user never repeats a fact.
\item \textbf{Skull-bound} — never exceeds the window; permanent tier has a hard ceiling.
\item \textbf{Decay \& demotion} — stale facts fade and demote automatically (even with the curator off).
\item \textbf{Immediate control} — ``remember / forget / correct'' applies instantly and sticks.
\item \textbf{Default-on; off $\Rightarrow$ simple \texttt{MEMORY.md}} — one flag, two paths; the fallback reuses the same tool + render, minus curator/decay/tiers.
\item \textbf{Coexists with $\lambda$-Memory} (opt-in, conversation-only today) without changing it.
\end{enumerate}

\section{Coexistence with $\lambda$-Memory (no conflict)}
$\lambda$-Memory today is off by default (gated by \texttt{shared\_memory\_strategy}; opt-in via \texttt{/memory lambda}) and stores only \texttt{Conversation} turns. Engram reuses its storage + decay/FTS code but is a separate feature: distinct \texttt{memory\_type=Permanent}, its own write path (the tool), its own default-on flag (works in Echo mode), and always-on (scope-filtered) injection. \texttt{/memory echo|lambda} is unchanged.

\section{Scoring \& lifecycle (hardened formulas)}
Each fact stores an importance $I$ and \texttt{last\_accessed}; everything else is derived lazily at read time (scores are never stored — same principle as $\lambda$).
\begin{keybox}
\textbf{Seed} (first time a fact is judged, importance $\hat I\in[0,5]$): \quad $I \gets \hat I$\\[2pt]
\textbf{Update} (re-judged or reinforced): \quad $I \gets \mathrm{clip}\big((1-\eta)\,I + \eta\,\hat I,\;0,\;5\big)$,\quad $\texttt{last\_accessed}\gets\text{now}$\\[2pt]
\textbf{Effective importance} (lazy, read-time):\quad $I_{\text{eff}} = I\cdot e^{-\Delta t/\tau}$,\quad $\Delta t=\max(0,\ \text{now}-\texttt{last\_accessed})$\\[2pt]
\textbf{User pin}: $I_{\text{eff}}=5$ always (no anneal; only the user unpins).
\end{keybox}
\textbf{Tiering (hysteresis, no flapping):} pinned $\lor\ I_{\text{eff}}\ge\theta_\uparrow \Rightarrow$ \textsc{Permanent};\quad (\textsc{Permanent} $\land\ I_{\text{eff}}\le\theta_\downarrow) \Rightarrow$ demote to $\lambda$;\quad $I_{\text{eff}}<\varepsilon \Rightarrow$ archived (hash).
\begin{itemize}[itemsep=0pt]
\item \textbf{``Stated once is enough''} — a confidently-judged fact ($\hat I\ge\theta_\uparrow$) is permanent on first write; an unsure one ($\hat I$ low) stays in $\lambda$ and is promoted only if the agent keeps judging it relevant. No \emph{user} repetition either way.
\item \textbf{Forgetting is curator-independent} — the lazy anneal drags $I_{\text{eff}}$ down with disuse, so stale facts demote by pure math even if the curator is off.
\item \textbf{Recency is free} — using a fact resets \texttt{last\_accessed}, so $I_{\text{eff}}$ already encodes ``recently relevant'' — one constant $\tau$, no separate recency term.
\end{itemize}

\section{Skull binding (holds on every model)}
\[ \text{bone}+\text{active}+\text{blueprint}+\underbrace{\text{permanent}}_{\le P_{\max}}+\underbrace{\lambda\text{-rem}}_{\text{absorbs rest}}+\text{reserve}+\text{guard}\ \le\ \text{skull}. \]
$\text{permanent}_{\text{render}}=\min\!\big(P_{\max},\ \text{free space}\big)$, ranked by $I_{\text{eff}}$. If a small-context model leaves little room, permanent \textbf{degrades fidelity} (full$\to$summary$\to$essence), then renders only the top-$I_{\text{eff}}$ subset \emph{this turn} — it is never demoted for lack of space, and the window never overflows. Budgeted against $1.15\times\texttt{estimate\_tokens}$ for the $\text{len}/4$ heuristic's error.

\section{Long-term behavior — timeproof}
Over months/years nothing drifts or saturates: $I\in[0,5]$ is clipped; context is bounded by $P_{\max}$; on-disk storage is bounded by GC; the anneal guarantees forgetting \emph{without} an LLM; no counter grows unbounded (timestamps are \texttt{u64} seconds). Behavior is identical across models because every budget is \emph{Skull-relative}, not a flat number. A fact's whole life — promote, persist, anneal, demote, recall — is one formula evaluated lazily.

Heavy user ($\sim$100 turns/day, $\sim$30\% substantive $\Rightarrow$ $\sim$30 curator calls/day): $\sim$1.2M in + 120k out / month. Illustrative: self-hosted $\approx\$0$; mid-tier $\approx\$0.8$/mo; flagship $\approx\$5$/mo. Prompt caching cuts the input further. \textbf{Cadence is the cost dial:} per-substantive-run (default) $\cdot$ every $N$ $\cdot$ session-end $\cdot$ off. \textbf{Engram off (MEMORY.md fallback) $\Rightarrow$ Curator $=\$0$.}

\section{Summary}
\textbf{Engram} is a default-on \emph{core tool}: the agent remembers/updates/forgets in natural language; a deterministic math layer seeds, smooths (EMA), forgets (lazy anneal), bounds (Skull cap), scopes, and GCs — and is the trust boundary that the optional LLM Curator cannot violate. Promotion is the agent's judgment (once is enough); demotion is pure math (timeproof even with the curator off); user pins are instant and immutable. It reuses $\lambda$-Memory's engine yet coexists cleanly, and degrades to a simple capped \texttt{MEMORY.md} when disabled. Bulletproof (failure-mode guards), timeproof (clipped + bounded + Skull-relative), token-efficient, and low-touch.
